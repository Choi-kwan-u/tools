SRT 자막 도구

자막 시간 밀기·합치기·검사를 서버 전송 없이 브라우저 안에서 처리합니다.

파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

파일을 고르면 내용이 아래 입력란에 채워집니다. UTF-8로 먼저 읽고, 깨지면 EUC-KR로 다시 읽습니다.

    SRT 자막 파일의 구조
    
      
    SRT(SubRip Text)는 가장 널리 쓰이는 자막 형식입니다. 전용 프로그램 없이 메모장으로 열어 고칠 수 있을 만큼 구조가 단순합니다. 자막 한 개는 번호, 타임코드, 텍스트로 이루어진 하나의 블록이고, 블록과 블록 사이는 빈 줄 하나로 구분합니다.
    
      
    
        
    
          
    줄내용예시
    
          
            
    1번째 줄자막 번호. 1부터 순서대로 매깁니다.1
    
            
    2번째 줄시작 시각 --> 종료 시각. 시:분:초,밀리초 형식입니다.00:00:01,000 --> 00:00:03,000
    
            
    3번째 줄부터화면에 보일 텍스트. 보통 1~2줄입니다.첫 번째 자막입니다.
    
            
    마지막빈 줄. 다음 블록과 구분합니다.(비어 있음)
    
              
        
    
      
    
      
    밀리초 구분자는 원래 콤마(,)이지만 점(.)을 쓴 파일도 흔히 보입니다. 이 도구는 두 가지를 모두 읽어 들이고, 내보낼 때는 표준 형식인 콤마와 세 자리 밀리초로 통일합니다. 줄바꿈이 윈도우식(CRLF)이든 유닉스식(LF)이든, 번호가 빠져 있든, 블록 사이에 빈 줄이 여러 개 있든 최대한 읽어 들이며, 밀기와 합치기 결과는 번호를 1부터 다시 매겨 저장합니다.
    

      
    자막 싱크가 어긋나는 흔한 원인
    
      
    자막이 영상과 맞지 않을 때는 먼저 처음부터 끝까지 똑같이 어긋나는지, 아니면 뒤로 갈수록 점점 벌어지는지를 확인하는 것이 좋습니다. 원인에 따라 고치는 방법이 다르기 때문입니다.
    
      
      
        
    • 인트로·광고가 잘리거나 추가된 경우 — 영상 앞부분 길이가 달라지면 자막 전체가 같은 양만큼 밀립니다. 가장 흔한 경우이며, 첫 대사가 들리는 순간과 첫 자막의 시작 시각 차이를 재서 시간 밀기 탭에 넣으면 한 번에 해결됩니다.
      • 
        
    • 프레임레이트 차이 — 23.976fps용 자막을 25fps 영상에 쓰면 처음에는 맞다가 뒤로 갈수록 점점 어긋납니다. 재생 속도가 약 4% 다르기 때문입니다. 이런 경우 일정한 시간을 미는 것만으로는 해결되지 않고 타임코드 전체를 비율로 늘리거나 줄여야 하므로, 전문 자막 편집기를 쓰는 편이 좋습니다.
      • 
        
    • 편집본 차이 — 극장판·감독판·방송용처럼 장면이 추가되거나 잘린 편집본은 구간마다 오차가 달라집니다. 특정 장면 이후만 밀어야 하므로 파일을 그 지점에서 나누어 따로 민 뒤, 합치기 탭으로 다시 이어 붙이는 방법을 쓸 수 있습니다.
      • 
        
    • 영상이 1부·2부로 나뉜 경우 — 두 영상을 하나로 합쳤다면 두 번째 자막을 첫 번째 영상 길이만큼 밀어 이어 붙여야 합니다. 합치기 탭은 첫 번째 자막의 마지막 종료 시각을 기준으로 오프셋을 자동 제안하므로, 필요하면 실제 영상 길이에 맞게 고쳐 쓰세요.
      • 
      
    

      
    방송 자막 글자수 관행
    
      
    방송사나 OTT의 자막 가이드라인은 매체마다 조금씩 다르지만, 일반적으로 아래와 같은 범위를 권하는 경우가 많습니다. 자막은 집중해서 읽는 글이 아니라 화면을 보는 동안 스쳐 지나가는 글이므로, 한 번에 눈에 들어오는 길이와 충분한 노출 시간이 중요합니다.
    
      
    
        
    
          
    항목일반적인 관행
    
          
            
    한 줄 글자수한글 기준 12~16자 안팎(공백 포함)
    
            
    줄 수최대 2줄
    
            
    노출 시간1~7초. 짧은 감탄사도 1초 이상
    
            
    자막 사이 간격겹치지 않게, 보통 2프레임 이상 띄움
    
            
    읽기 속도초당 4~6자 정도
    
              
        
    
      
    
      
    검사 탭은 이런 관행을 기준으로 한 줄 글자수 상한(기본 16자)을 넘는 자막, 1초 미만으로 노출되는 자막, 이전 자막과 시간이 겹치는 자막, 번호가 빠지거나 순서가 어긋난 자막을 찾아 줍니다. 글자수는 공백을 포함해 유니코드 코드포인트 단위로 세므로 이모지나 특수문자도 한 글자로 계산됩니다. 유튜브처럼 가로 폭이 넓은 매체라면 상한을 20자 안팎으로 올려 검사해도 괜찮습니다.
    

      
    사용 방법과 주의할 점
    
      
      
        
    1. SRT 파일을 열거나 자막 내용을 그대로 붙여넣습니다. 인코딩은 UTF-8로 먼저 읽고, 깨지면 EUC-KR(CP949)로 다시 읽습니다. 예전 윈도우에서 만든 한글 자막도 대부분 정상적으로 열립니다.
      2. 
        
    2. 시간 밀기 탭에서 초 단위로 이동량을 넣으면 미리보기가 즉시 바뀝니다. 양수는 자막을 늦추고 음수는 앞당깁니다. 0초보다 앞으로 가는 자막은 00:00:00,000으로 맞춥니다.
      3. 
        
    3. 합치기 탭에서 두 번째 자막을 넣고 오프셋을 확인한 뒤 내려받으면, 번호가 1부터 다시 매겨진 하나의 파일이 됩니다.
      4. 
        
    4. 검사 탭에서 문제 목록의 항목을 누르면 미리보기에서 해당 자막이 표시됩니다. 내용 수정은 원본 편집기에서 하고 다시 검사하면 됩니다.
      5. 
      
    
      
    모든 처리는 브라우저 안에서만 이루어지며 파일이 서버로 전송되지 않습니다. 내려받는 파일은 UTF-8로 저장되므로, 오래된 재생기에서 한글이 깨진다면 재생기의 자막 인코딩 설정을 UTF-8로 바꾸세요.
